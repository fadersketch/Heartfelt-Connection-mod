# Heartfelt-connection (心契誓约 × 爱憎分明)

《心契誓约》(maidmarriage) × 《爱憎分明》(Love & Loathe) 的**关系联动补丁**——让两只模组的女仆关系系统真正协同工作，并把完整的关系状态注入 AI 对话，女仆从此"记得你、在乎你、会主动走向你"。

- **Minecraft**:1.20.1
- **加载器**:Forge 47.4.21(1.20.1-47.4.21)
- **许可证**:MIT
- **仓库**:github.com/fadersketch/Heartfelt-Connection-mod
- **版本**:v1.0.0

> 开发过程中使用了 AI 辅助编程工具;作者并非专业程序员,代码中可能存在缺陷,遇到问题欢迎反馈。

## 🔧 它是如何做到"两个模组兼容"的？（用户最关心的问题）

三个前置模组各管一摊：TLM 管好感与女仆本体、maidmarriage 管结婚/家庭/女儿、callresponse 管信任/恐惧/饥饿。heartfelt 不修改任何原模组文件，用三层机制把它们缝在一起：

### 1. 编译期零依赖，运行时反射调用
- 编译 classpath 只依赖 **TLM 官方 API**（`@LittleMaidExtension` 扩展机制）；maidmarriage 与 callresponse 的类**从不直接 import**，全部走字符串类名 + 反射（`ReflectUtil`）；
- 反射层**只缓存成功的调用**、失败下次重试（模组加载有先后，早期探不到不永久降级）、所有调用安全降级不抛异常——**任一前置缺失或版本变动，本模组照常加载**，只是相关功能静默不生效。

### 2. 数据桥接：读双方的存档，写回双方
- **读 maidmarriage**：通过 TLM 的 `TaskDataRegister` 解析 maidmarriage 注册的六张数据表（`marriage_data` 婚姻 / `relationship_progress_data` 告白进度 / `child_state_data` 女儿阶段 / `lineage_data` 血统 / `pregnancy_data` 孕期产后 / `mood_data` 心情），record accessor 反射读取——本模组**从不复制一份"关系状态"**，永远读原模组的权威数据；
- **写 maidmarriage**：告白完成、加心情、解除关系、开启/关闭互动面板等，调它的公共 API（反射兜底）；
- **读 callresponse**：信任/恐惧/饥饿数值反射读取；饥饿系统总开关（`misc.loveLoatheHungerOff`）直接控制爱憎分明的饿死/撑死/自动吃腐肉；
- **写自己**：本模组自己的状态（告白时间戳、主人"名花有主"标记、记忆事件）存 TLM 的 persistentData 与存档文件——**零跨模组依赖的状态通道**。

### 3. Mixin 运行时补丁，分两层配置
- `mixins.heartfelt.json`（required=true）：只注入 TLM 本体与安全的可选目标（`@Pseudo` + 字符串 targets + `require=0`），目标不存在静默跳过；
- `mixins.heartfelt.opt.json`（required=false + `defaultRequire=0`）：针对 maidmarriage/callresponse 的注入（女儿文本池、抱起坐姿、攻击限伤、语音包拦截等 9 个）——**目标类不存在或版本变动只警告不崩溃**（历史上注入失败导致启动崩溃的问题已根治，见 v1.5.14/v1.5.15）。

一句话：**不改任何原模组文件，运行时用反射读写双方数据、用可选 Mixin 注入行为，任一前置缺失或版本不匹配都安全降级。**

## 💞 女仆的情感路线(从陌生到家人,一条完整的心路)

### 第一层:数值地基(三个模组各管一摊,heartfelt 把它们统一起来)
- **好感**(TLM favorability,0~384):决定亲疏的四档——0-63 礼貌疏离 / 64-191 友善可接近 / 192-383 温暖依恋 / 384 黏人占有;
- **信任 / 恐惧**(callresponse):随你的互动起伏——喂食/送礼涨信任,伤害/背叛涨恐惧;
- **心情**(maidmarriage mood):事件驱动,告白成功 +2、被拒 -6,伤心时锁定沮丧档;
- **中和缓和**(heartfelt 新增):未确认关系的女仆,好感会自然把信任/恐惧推向忠诚——喂得好她越来越信任你,冷落她好感掉的信任也会跟着松动。

### 第二层:心动(好感 192 以上,暗恋期)
- 好感跨过 192 线,女仆开始"意识到喜欢你"——**周期性主动告白尝试**(概率随好感线性上升,满好感每次尝试窗口约 95%);
- 告白前有完整前摇:威胁检查 → 系统消息 → 走向你 → 走到身边才弹告白界面(不再突然突脸);
- **玩家主动告白**同样支持:你开口,她回应——接受成恋人,婉拒不惩罚。

### 第三层:确认关系(恋人/妻子)
- **恋人**:告白完成即确认——信任/恐惧**完全冻结**(不再背叛、不再淡忘),吃醋被绝对压制(主人名花有主,其他女仆不再争风);
- **妻子**:结婚是永久契约——家庭保护、特殊奶、产后窗口、婚纱模型(花嫁酒狐)随之解锁;
- **纪念日**:7/30/100/365 天里程碑,她会记得你们第一次见面/告白的那天。

### 第四层:家庭(女儿线,四阶段成长)
- 女儿从**婴儿**开始:不会说话只会咿呀、强制坐下、拿不住武器、禁语音包;
- 成长到**幼儿**:能走、能说简单短句,依然被呵护;
- 成长为**少女**:活泼撒娇的小女孩,专属文本池(摸头/抱抱/送礼/学习归来各按天轮换);
- 成年**女儿**:懂事的父女向互动——照顾爸爸、整理家务、催休息,父女称呼铁律(爸爸/父亲),防乱伦保护(LLM 也不越界)。

### 第五层:波折与修复(关系也会受伤,但可以修)
- **伤心窗口**:你连续伤害她(30 秒内 3 次,误伤豁免)——她坐着赌气、拒绝对话、沮丧锁定,窗口到期自动和好;
- **关系破裂**:恋人好感跌破告白线——关系破裂、心碎记忆、冻结解除,她不再主动;
- **背叛与悔改**:被逼到背叛的女仆,可以靠持续喂食安抚和解——她清醒过来,重新认你为主;
- **思慕**:好几天不亲近,她会想你(心形粒子 + 思慕对话)。

## ✨ 新添机制一览

### AI 对话层
- **关系栏注入**:结构化关系状态(`<context>`:你是谁、她是谁、你们什么关系)随每次对话送给 LLM;
- **提示词运行时注入**:favorability 四档量表 + 关系专属准则(妻子/恋人/女儿各按阶段),女儿线带防乱伦铁律;
- **事件历史**:首见/首礼/告白发起方/救主/破裂史注入提示词——她的记忆有迹可循;
- **情境变量**:饥饿/昼夜/群系/主人状态进上下文;
- **后果文本弧**:被拒后/破裂后/和好后的相处模式各不相同;
- **演绎剧情按钮**:Alt+J 对话面板新增,按共同记忆沉浸式演绎剧情(需 LLM,无 LLM 降级提示)。

### 互动与表现
- **玩家主动告白屏**:粉色透明面板,玩家开口 + 女仆回应,方向修正;
- **对话安全区**:告白/对话前周围无敌对生物才允许,先打怪再谈情;
- **选择性静止**:对话期间其他生物定住,你与目标女仆可动;
- **亲密互动工具**:hug/kiss/lap/pet 供 LLM 对话调用(女儿有隔离保护);
- **抱起回应 / 思慕明显效果 / 死亡调侃 / 特殊奶增强**(解除负面+回血,妈妈三档口吻);
- **调整器(测试工具,形象=纸)**:一键调整好感/关系(恋人/妻子/女儿/解除)/心情/信任恐惧/成长阶段/时间快进/纪念日重置,方便验证全部功能。

### 修复与保护
- 灵体不播语音包、婴儿幼儿语音彻底禁、幼儿任务锁空闲/手持限食物;
- 女儿永不背叛、魂符收妈妈时女儿强制坐下等待;
- 玩家伤害限伤修复(识别爱憎分明重放伤害)、对话面板中文换行居中重做;
- 调整器/调试面板界面自适应小窗口。

## 📦 安装

1. 安装 Minecraft 1.20.1 + Forge 47.4.21 + 三个前置模组(见上表);
2. 下载 `heartfelt_connection-1.0.0.jar` 放入 `mods` 文件夹;
3. (可选)安装 [Promaid](https://github.com/fadersketch/Promaid-mod) 获得完整联动体验。

## 从源码构建

仓库自带一键构建链(仅 Windows,需要 JDK 17+):

```
gen_compile.py        # 扫描 heartfelt_src 自动生成编译参数(需先准备 compile_addon.txt 类路径)
compile_heartfelt.bat # javac 编译,输出 out_heartfelt
build_heartfelt.py    # 组装 jar(classes + 资源 + META-INF + LICENSE)→ patched/heartfelt_connection-1.0.0.jar
```

编译需要完整的 Forge 1.20.1 开发类路径(可直接使用 `.minecraft/libraries` 下的库 + 原版 TLM/maidmarriage/callresponse jar),按 `compile_addon.txt` 的格式写入本地路径后运行。
